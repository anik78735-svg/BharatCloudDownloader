# 🚀 Unified Social Media Downloader Platform

**Instagram Reels + TikTok + Facebook** — One powerful API + Web UI + SDK

## Features

- ✅ Auto platform detection
- ✅ Multi-fallback extraction engines
- ✅ Real file download → saves into `downloads/` folder
- ✅ Device preview (video player in browser)
- ✅ Full CORS open
- ✅ Health endpoint
- ✅ Public REST API for other developers
- ✅ Python SDK included
- ✅ Beautiful Web UI

## Quick Start

```bash
cd unified_downloader
pip install -r requirements.txt

# (Optional) Instagram ke liye RapidAPI key set karo
export RAPIDAPI_KEY=your_key_here

python main.py
